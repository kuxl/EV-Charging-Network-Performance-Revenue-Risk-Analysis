# EV Charging Sessions EDA & Statistical Analysis

A Python data analysis project using **Exploratory Data Analysis (EDA), statistical analysis, and feature engineering** to analyze **EV charging sessions, charging behavior, energy consumption, revenue, costs, and session outcomes**.

## 🎯 Objectives

* **Clean and preprocess** the EV charging dataset
* Analyze **charging patterns and session behavior**
* Compare **cities, charger types, vehicle types, and user types**
* Analyze **energy consumption, revenue, and energy costs**
* Analyze **completed, failed, and interrupted sessions**
* Apply **statistical analysis** to validate relationships
* Create **meaningful features** for deeper analysis

## 🔍 Key Analysis

* **City-wise charging session analysis**
* **Charger-type performance**
* **Vehicle-type analysis**
* **User-type analysis**
* **Session status analysis**
* **Energy consumption patterns**
* **Charging duration and waiting-time analysis**
* **Revenue and energy-cost analysis**
* **Charging demand patterns**
* **Completed vs Failed vs Interrupted sessions**
* **Correlation and relationship analysis**
* **Operational performance analysis**

## 🛠️ Technologies Used

**Python • Pandas • NumPy • Matplotlib • Seaborn • SciPy**

💡 **Key Insights**

Identified **charging behavior, energy consumption patterns, session outcomes, revenue and cost trends, charger performance, and operational factors** affecting EV charging sessions through **EDA, statistical analysis, and feature engineering**.
