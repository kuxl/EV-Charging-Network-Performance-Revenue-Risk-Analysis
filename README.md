EV Charging Sessions EDA & Statistical Analysis

A Python data analysis project using Exploratory Data Analysis (EDA), statistical analysis, and feature engineering to analyze EV charging sessions, charging behavior, session outcomes, energy consumption, revenue, and operational performance.

🎯 Objectives
Clean and preprocess EV charging session data
Analyze charging patterns and session behavior
Compare cities, charger types, vehicle types, and user segments
Analyze energy consumption, revenue, and energy costs
Identify failed and interrupted charging sessions
Apply statistical analysis to validate key relationships
Engineer meaningful features for business insights
🔍 Key Analysis
City-wise charging session analysis
Charger-type performance
Vehicle-type and user-type analysis
Session status analysis
Energy consumption patterns
Charging duration and waiting-time analysis
Revenue and energy-cost analysis
Charging demand patterns
Failed vs interrupted vs completed sessions
Correlation and relationship analysis
Operational performance analysis
📊 Statistical Analysis
Hypothesis testing
Group-wise statistical comparisons
Relationship analysis between charging variables
Statistical validation of charging and session patterns
⚙️ Feature Engineering
Time-based charging features
Charging performance metrics
Revenue and cost-based metrics
Session outcome indicators
Operational efficiency features
🛠️ Technologies Used

Python • Pandas • NumPy • Matplotlib • Seaborn • SciPy

💡 Key Insights

Analyzed 86K+ EV charging sessions to identify charging behavior, energy consumption patterns, session outcomes, revenue and cost trends, charger performance, and operational factors affecting EV charging sessions. The analysis also identified 95 duplicate session records and addressed missing values through data preprocessing.
